# 🧠 Trishula-Memory
**Sovereign, Framework-Free Persistent Agent Memory Engine**  
*Built by Trishula Software | Anti-Epeolatry Architecture*

## Overview
Trishula-Memory is the de-wrapped, sovereign evolution of `mem0ai/mem0`. It strips all LangChain, LangChain-Core, LiteLLM, and cloud telemetry hooks, replacing them with a battle-hardened SQLite and semantic index that runs 100% locally with zero cloud dependencies.

## Key Features
- **100% Sovereign & Local:** Pure SQLite storage. Zero external SaaS accounts or API rent.
- **De-Wrapped Architecture:** Zero dependencies on LangChain or fragile abstraction layers.
- **Cross-Session Durability:** Instant recall of user preferences, system autopsies, and win/loss ledgers.
- **Sub-5ms Recall:** High-performance indexing with zero framework latency overhead.
